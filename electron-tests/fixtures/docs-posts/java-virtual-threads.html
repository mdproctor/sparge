Java 21 Virtual Threads

February 3, 2026 Mark Proctor

Virtual threads, introduced in Java 21, make it easy to write highly concurrent code without the overhead of OS threads.

Creating a Virtual Thread

Thread.ofVirtual().start(() -> {
    System.out.println("Running in a virtual thread");
});

Using an Executor

For managing many threads, use the virtual thread executor:

try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    IntStream.range(0, 1000).forEach(i -> {
        executor.submit(() -> processRequest(i));
    });
}

This creates one virtual thread per task, with minimal memory overhead compared to platform threads.
