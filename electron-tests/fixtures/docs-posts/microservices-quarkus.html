Building Microservices with Quarkus

March 5, 2026 Mark Proctor

Quarkus is a Kubernetes-native Java framework designed for microservices and serverless applications.

Project Setup

Create a new Quarkus project using the CLI or the web configurator at code.quarkus.io. Select the extensions you need — REST, Hibernate, Kafka — and generate the project.

REST Endpoints

Quarkus uses JAX-RS annotations for REST endpoints. Combined with native compilation, endpoints start in milliseconds with minimal memory footprint.

Testing

Quarkus provides @QuarkusTest for integration tests that start the full application in test mode, giving you confidence that your endpoint works end-to-end.
